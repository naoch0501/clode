# 録音素材の準備

声の再現度は、学習量よりも **素材の質** に大きく左右されます。

## 量
- 合計 **30 分〜1 時間** あれば十分に実用的な品質になる。数時間あるとさらに安定する。
- 長いファイルのままでかまわない。`train.sh prepare` が無音区間で 2〜12 秒ごとに自動分割する。

## 質
| 項目 | 推奨 |
|---|---|
| 形式 | wav / flac（mp3・m4a も可だが非圧縮の方がよい） |
| サンプリングレート | 44.1kHz 以上（学習時に 44.1kHz に揃えられる） |
| 雑音 | エアコン・PC ファン・反響ができるだけ少ない部屋で録る |
| BGM・効果音 | **入れない**（配信アーカイブなどは BGM を除去してから使う） |
| 他人の声 | 入れない。混ざると声質がぶれる |
| 音量 | ピークが割れない程度。`--normalize` で自動的に揃うので神経質にならなくてよい |
| 話し方 | 喋らせたい口調で録る。平坦な朗読だけだと平坦に、感情豊かに録ればそのように喋る |

文章は ITA コーパスなどの読み上げ用文章を読むと、音素がまんべんなく揃うので効率がよい。

## 文字起こしの確認（重要）
`train.sh prepare` のあと、`Style-Bert-VITS2/Data/<モデル名>/esd.list` を開いて誤りを直す。

```
myvoice_0001.wav|myvoice|JP|今日はいい天気ですね。
```

- 形式は `ファイル名|話者名|JP|テキスト`。
- 聞き取りの誤りや抜けを直す。数字・英字は読み方どおりにひらがな・カタカナで書くと安全。
- 咳・笑い声だけ、ノイズだけのような行は **行ごと削除** する。
- 音声は `Data/<モデル名>/raw/` にあり、Windows からダブルクリックで再生して確認できる。

## 学習量の目安
- 既定は 100 エポック。素材 30 分・batch 4 で RX 9070 XT なら数時間程度の見込み（環境によって大きく変わる）。
- `SAVE_EVERY`（既定 1000 ステップ）ごとに `model_assets/<モデル名>/` へ保存される。途中の保存ファイルも `speak.py --checkpoint` で試せるので、聞き比べて一番よいものを使えばよい。学習しすぎると逆に不自然になることもある。
