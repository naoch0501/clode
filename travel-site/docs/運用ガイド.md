# 運用ガイド

## 全体の流れ

```
地域とテーマを決める → 記事を書く（実体験 + Claude Code で整える）→ 公開 → 検索から読者が来る → リンク経由の予約で報酬
```

検索から人が来るまで、新しいサイトだと**3〜6か月**かかるのが普通です。最初の数か月は収益ゼロが当たり前と考えて、記事を積み上げてください。目安は **最初の3か月で20〜30記事** です。

---

## ステップ1: 公開する（Cloudflare Pages・無料）

1. [Cloudflare](https://dash.cloudflare.com/) に無料登録する
2. 「Workers & Pages」→「Create」→「Pages」→「Connect to Git」でこの GitHub リポジトリを選ぶ
3. ビルド設定を次のようにする
   - Framework preset: `Astro`
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Root directory: `travel-site`
4. 公開されると `xxxx.pages.dev` の URL がもらえる
5. 独自ドメイン（年1,500円前後）を取ったら Cloudflare に設定し、`src/site.config.ts` の `url` を書き換える

> 独自ドメインは早めに取るのがおすすめです。あとから変えると、それまでの検索評価を引き継ぐ手間がかかります。

公開したら [Google Search Console](https://search.google.com/search-console) にサイトを登録し、`https://あなたのドメイン/sitemap-index.xml` を送信してください。どんな検索語で表示されているかが分かるようになります。

---

## ステップ2: アフィリエイトに登録する

記事が数本ある状態のほうが審査に通りやすいので、**5〜10記事を公開してから**申し込むのがおすすめです。

| サービス | 向いている記事 | メモ |
|---|---|---|
| **Travelpayouts** | 全般 | Klook・GetYourGuide・Airalo など多数の旅行系をまとめて扱える窓口。最初はここ1つで十分 |
| Klook | ツアー・体験・交通パス | アジア圏の旅行者に強い |
| GetYourGuide / Viator | ツアー・体験 | 欧米の旅行者に強い |
| Booking.com / Agoda | 宿泊 | 「Where to stay」記事で使う |
| Airalo など eSIM | 実用情報 | 訪日客のほぼ全員に必要なので成約しやすい |

- 報酬率や条件はサービスごとに違い、変わることもあるので、登録時に必ず確認してください
- 新しいサービスのリンクを使い始めたら、そのドメインを `src/site.config.ts` の `AFFILIATE_DOMAINS` に追加してください（`rel="sponsored"` が自動で付きます）
- 報酬は PayPal や銀行振込で受け取れるものが多いです。年20万円を超えたら確定申告が必要です

## ステップ3: 書く記事を決める

### 狙い目の記事タイプ（成約しやすい順）

1. **モデルコース**: 「2 days in 〇〇」「〇〇 itinerary」。ツアー・宿・交通のリンクを自然に置ける
2. **アクセス**: 「How to get from 〇〇 Airport to 〇〇」。検索需要が安定していて、交通パスにつなげやすい
3. **宿エリアの比較**: 「Where to stay in 〇〇」。宿泊は単価が高い
4. **比較・判断系**: 「Is 〇〇 worth it?」「〇〇 vs △△」
5. **体験・グルメ**: 「Best 〇〇 in 〇〇」。具体的な店や体験と写真が勝負

### キーワードの探し方

- Google で英語検索したときの「他の人はこちらも質問」と、検索窓のサジェスト
- Reddit の r/JapanTravel でその地域名を検索し、**よくある質問**を拾う（そのまま記事のネタになります）
- 公開後は Search Console で「表示されているのにクリックされていない検索語」を見て、記事を追記する

## ステップ4: Claude Code で記事を作る手順

**大事な原則:** 中身（行った場所、感想、写真、値段）はあなたの実体験。Claude Code は構成・英語・事実確認・サイト作業を担当します。AI だけで書いた一般論の記事は、検索でも読者にも評価されません。

### 1. 体験メモを日本語で書く

箇条書きで十分です。

```
- 〇〇城：駅から徒歩15分。入場料400円（2026年11月に確認）
- 朝9時の開門直後は空いている。10時を過ぎると団体客が来る
- 天守からの眺めより、裏の庭園のほうがよかった
- 近くの△△という店で□□を食べた。1,200円。英語メニューあり
```

### 2. Claude Code に頼む

```
src/content/guides/template-itinerary.md の形式で、
下のメモから「2 Days in 〇〇」の記事を英語で書いて。
メモにない事実は追加せず、確認が必要なところは [CHECK] と書いて。

（メモを貼る）
```

### 3. 自分で確認する

- `[CHECK]` の箇所を自分で調べて埋める
- 料金・営業時間・アクセスが正しいか見る
- `npm run dev` で表示を確認する
- 写真を `public/images/` に置いて記事に入れる

### 4. 公開する

`draft: false` にしてコミット・プッシュすると、Cloudflare Pages が自動で公開します。

## 定期的にやること

| 頻度 | 作業 |
|---|---|
| 毎週 | 記事を1〜3本追加 |
| 毎月 | Search Console で検索語を確認し、表示が多い記事に追記する |
| 3か月ごと | 料金・営業時間・閉店などを確認し、`updatedDate` を更新する |

## 注意点

- **他人の写真や文章は使わない。** 写真は自分で撮る
- **予約の代行（代金を預かって手配）はしない。** 旅行業の登録が必要になります。リンクを貼るだけなら問題ありません
- **アフィリエイトであることを明示する。** 記事冒頭の表示と Disclosure ページは消さないでください
- **個人情報に注意。** 自宅が特定できるような写真や書き方は避ける
